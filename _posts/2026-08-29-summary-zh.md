## [chrome-devtools-mcp 让 AI 编程智能体直接控制 Chrome DevTools](https://github.com/ChromeDevTools/chrome-devtools-mcp) ⭐️ 8.0/10

ChromeDevTools 发布了 chrome-devtools-mcp，这是一个托管在 npm 上的开源 MCP 服务器，可让 Claude、Cursor、Copilot 等编程智能体控制和检查实时 Chrome 浏览器。它将 DevTools 的自动化、调试和性能分析能力开放给智能体，并附带一个无需 MCP 即可使用的命令行工具。 它把 AI 辅助编程与真实浏览器检查联系起来，让智能体能在实时 Chrome 环境中测试、调试和分析网页，而不只是生成代码。随着 MCP 生态的壮大，来自官方的 DevTools 集成为 AI 编程工具提供了一种标准化、可靠的处理浏览器任务的方式。 该服务器使用 Puppeteer 进行自动化，并利用 Chrome DevTools 进行性能追踪、网络分析、截图和带源码映射的控制台消息检查。默认会收集使用统计信息，可通过 --no-usage-statistics 关闭；性能追踪数据可能会发送到 CrUX API，除非传入 --no-performance-crux；官方仅支持 Chrome 和 Chrome for Testing。

## [研究发现 LLM 在经济博弈中表现出心智化能力](https://arxiv.org/abs/2608.26291) ⭐️ 8.0/10

研究团队让 DeepSeek、GPT-4.1、GPT-5 和 Gemini 2.0 Flash 这四类模型的 2,099 个智能体参与两个经济博弈，并以 251 名人类参与者为基准，用认知计算建模识别潜在的心智化策略。结果显示，LLM 表现出清晰的行为与计算层面的心理化特征，且因模型供应商和规模不同而差异显著，其中 GPT-5 甚至超过了人类。 这项研究提供了经验证据，表明 LLM 不仅能通过心理理论测试，还能运用类似心理化的推理来指导适应性行为。它为在人类与 AI 之间比较社会认知提供了认知计算建模这一正式方法，对 AI 安全、人机交互和模型评估都有意义。 策略性提示通常通过诱导更复杂的推理来提升表现，但收益因任务而异。GPT-5 能根据对手的复杂程度灵活调整自己的递归推理深度，表现优于人类；不同模型家族的心智化能力差异明显。

rss · arXiv cs.AI · 8月28日 04:00

**背景**: 心理化（mentalization）是指推断他人信念和意图以指导自身行为的能力，它与心理理论（theory of mind）相关但更宽泛；心理理论通常侧重于对信念（尤其是错误信念）的认知理解。该研究使用经济博弈和认知计算建模——即用正式的计算模型模拟人类认知——来揭示人类和 LLM 共同的潜在推理策略。
